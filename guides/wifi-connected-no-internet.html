Connected to Wi-Fi, but no internet: isolate the break

The Wi-Fi icon can be full while the path to the internet is broken. Use a short sequence that distinguishes the wireless link, router, ISP and individual device.

SignalNook EditorialReviewed 11 Nov 2026
THE SHORT ANSWER

The Wi-Fi icon can be full while the path to the internet is broken. Use a short sequence that distinguishes the wireless link, router, ISP and individual device. Begin with a repeatable comparison and record one change at a time, rather than making several router changes together.

Understand what “connected” proves

A connected Wi-Fi indicator means the device has joined an access point; it does not establish that the router has a healthy connection to your provider. A device may show a strong wireless signal while its web requests fail. Conversely, a working internet service can appear unavailable if only one client has a DNS or VPN issue. Treat those as different hypotheses rather than restarting everything. Start with the extent of the problem: does a second phone on the same network reach the same ordinary website? Is the error limited to one app, or does it affect multiple unrelated sites?

Compare three paths before changing settings

First, try a second device on the same Wi-Fi. If both fail, look upstream toward the router or provider. Second, if available, temporarily test a computer using Ethernet to the router. A working wired path with a failing wireless path suggests a Wi-Fi-specific problem; both failing suggests WAN, modem, routing or service issues. Third, try the original device using another trusted connection, such as mobile data. If it works there but not at home, note the difference. These comparisons take less time than resetting a router and give you stronger evidence.

Inspect status, then restart carefully

Check the router or gateway dashboard if you already have access. Look for WAN connection state or an outage notice from your ISP. A modem might be physically connected but unable to authenticate or acquire service. If your provider recommends a restart, note current settings first, then restart equipment in the sequence documented by the manufacturer. Do not press a recessed factory-reset button: that can erase credentials, Wi-Fi names and custom network settings. If the router is managed by your ISP, ask before making configuration changes.

When it only affects one computer

On that device, disconnect and reconnect once, then examine whether VPN, proxy or security software is changing the network route. An authenticated captive portal can also block normal browsing even though Wi-Fi shows connected, particularly at hotels and public networks. Avoid immediately replacing DNS settings with random public servers; first determine whether name resolution is the failing step. A device that can reach a known IP but not a domain may point to DNS, but this is only one diagnostic clue.

What to tell your provider

Record whether the outage affects Wi-Fi and Ethernet, the approximate start time, the WAN status shown by the router, and any relevant service alerts. Share the observations rather than only “the Wi-Fi is broken.” If the provider confirms an upstream outage, changing your router settings will not restore the connection. If only Wi-Fi fails, continue with coverage and interference tests instead of escalating the broadband plan.

A worked example

Example: two phones show Wi-Fi connected but neither can load sites. A laptop attached by Ethernet also fails, while the ISP status page confirms an outage. That evidence points upstream; buying a stronger mesh system would not help.

How to interpret three common observations

The same visible symptom can have more than one cause. Use the comparisons below as test priorities, not as an automatic diagnosis of your particular equipment.

Every device fails, including Ethernet

A shared WAN, provider or gateway condition is more plausible than a radio dead zone. Check the gateway internet status and service notices before touching security settings.

One laptop fails, phones work

Investigate the laptop VPN, saved network profile, proxy and DNS rather than rebooting a network that serves everyone else.

Wi-Fi works after switching to mobile data

That only shows an alternative route works. Compare another household device to distinguish a home-network fault from one-device configuration.

Field checklist

  • Test two devices using the same site
  • Compare Wi-Fi and wired connectivity if safely available
  • Check router WAN status or ISP outage notices
  • Record the start time and exact error
  • Escalate with the comparisons you observed
Don't make this mistake

Do not factory-reset ISP equipment or alter DNS and firewall settings as the first move.
